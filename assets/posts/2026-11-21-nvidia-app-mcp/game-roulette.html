What the fuck is going on?

This page connects locally to the NVIDIA MCP server running on your PC at http://127.0.0.1:13508/mcp to find your games and launch the one selected by the wheel. This works because the MCP server is badly configured to respond with Access-Control-Allow-Origin: null. The null value is known to be problematic; as clearly mentionned in MDN documentation for Access-Control-Allow-Origin.

To disable it, open the NVIDIA app, then go to settings and uncheck 'Allow Agents to control NVIDIA App'.

This is not super critical though, since there does not seem to be an obvious way of doing something much worse than launching games, or tweaking game settings.
